# 飞域 · 无人机空域速查

网站展示用户提供 KML 内的 4,207 个多边形区域，替换了初版的虚构演示圆。支持全国地图、城市/原始机场名称/区域 ID 搜索、6 类筛选、图层开关、当前视野列表和区域详情，适配手机。

## 数据与来源

- 导入文件：`限飞区.kml`。`限飞区(1).kml` 与其 SHA256 完全一致，因此只导入一份；QGIS 工程引用的也是这份 KML。GDB、LYR 和 QGZ 未作为额外区域叠加，以免把不同软件的同源图层重复绘制。
- 文件自述来源：DJI FlySafe API；生成日期：2026-05-06。来源与现行有效性未经独立核验。
- 共 58,553 个边界坐标，逐点保留原始经纬度，未进行边界简化；KML 坐标为 WGS 84（EPSG:4326），与 OpenStreetMap 底图匹配。
- 分类：限飞/禁飞区 936、授权飞行区 649、警示区 2340、加强警示区 29、管制区 225、限制区 28。
- 原文件有部分境外区域，全部保留。“全国概览”仅为地图视角，不表示覆盖了全国所有限飞区域。“查看全部收录范围”可显示全部数据。
- 一个原始 ID 可能包含多个多边形分区。每个多边形独立保留，不按 ID 删除边界；同名区域在搜索中可能出现多项。
- 文件未提供可用的限高数值、有效期和实时更新。KML 的 0 高程不等于限高；授权飞行区也不表示用户已获得许可。无标记区域不代表可飞。

## 运行与更新

运行 `node server.cjs`，访问 `http://127.0.0.1:4173`。静态文件在 `dist`，无需构建。Leaflet 从 unpkg 加载，底图来自 OpenStreetMap，需要网络连接。

运行 `./scripts/import-airspace.ps1 -Source <KML路径>` 可重新转换同结构数据；来源与日期字段应根据新文件核对并更新。然后运行 `node scripts/verify-airspace.cjs <KML路径>`，核对源文件哈希、每个边界坐标、区域数量、分类和外接范围。实际展示数据为 `dist/data/airspace.geojson`。

地图使用 Canvas 绘制；缩小时补充区域中心点帮助查看分布，放大后按原始多边形展示。列表只呈现与当前视野外接矩形相交的记录并分批加载；分类筛选和图层开关同时生效，搜索始终查询完整数据集。
