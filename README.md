# 飞域 Airspace Explorer

低空空域与无人机物流规划分析平台 · 研究展示版 v3。

沿用原项目的纯静态架构与 Leaflet，保留空域数据和查询逻辑。新增 ES modules、Canvas 点层、Web Worker、城市分片与可重复预处理，不依赖后端数据库或 ChatGPT 登录。运行时依赖 Leaflet 1.9.4 已放在 `dist/vendor/leaflet`，保留其许可证；没有 npm 第三方依赖。

## 运行与构建

安装 Node.js 20 或以上版本。无需 npm install。在本目录运行：

```powershell
node server.cjs
```

打开 http://127.0.0.1:4173 。不要双击 index.html：模块、Worker 和数据请求需要 HTTP。可通过 PORT 与 HOST 环境变量配置监听地址；默认仅本机。支持 DecompressionStream 的现代 Chrome / Edge / Firefox / Safari 可读取压缩城市数据。

```powershell
node scripts/build.mjs
node --test tests/platform.test.mjs tests/server.test.mjs
python tests/preprocess_test.py
```

如果已安装 npm，也可使用 `npm start`、`npm run build`、`npm test`。本机验证使用 Node 直接命令（当前环境未提供 npm 命令）。构建检查 JavaScript 语法、HTML 资源和 369 个可部署城市分片；纯静态项目无需编译打包器，部署目录是 `dist`。

## 五个模块

- **空域速查**：原有 4,207 个 KML 多边形、六类筛选、图层开关、城市/机场/区域 ID 搜索、查看全部收录范围、定位、缩放及原始数据说明。
- **低空物流规划**：全国精确聚合需求分布；城市按需读取完整需求和 DZ/LD/DC 网络；需求权重热力、点聚合、物流类型/得分过滤、虚拟/非新增节点、土地分类/核查与节点状态组合过滤。
- **覆盖对比**：规划、原模型已覆盖、新增覆盖三种需求集合；点数/权重覆盖率图表、各级虚拟节点及新增覆盖量。原模型展示覆盖状态，不虚构历史网络几何。
- **数据分析**：全国、省份、城市指标；七类核心图表、城市排名；图表点击定位城市或筛选层级/类型；任意两地区比较。图表为所选地区全量指标，地图侧栏为对象筛选指标；城市页排名采用所在省范围。
- **数据与方法**：数据 SHA256、字段字典、验证结果、两份交付说明、算法与现实限制。

点击需求或节点，查看完整规划路径、直接上下级连接、原始字段、300/500 米 POI 结构、服务半径和模型共址成员。连接样式依据 coverage_action；直接下级默认最多绘制 200 条，全部关联可导出。点击下级按钮会进入对应子节点。关闭详情或清除高亮可移除关联线与半径。

需求点与网络节点支持“当前地区 + 当前筛选 + 可选当前视窗”的 CSV 导出，保留原始字段及覆盖/虚拟补充字段。另有城市完整 coverage、edges、facilities 和空 uncovered 表的导出。CSV 有 UTF-8 BOM、双引号转义及字符串公式注入防护。统计可导出地区指标。

地图范围统计使用点坐标落入视窗判断，不是行政边界裁剪。全国需求用按城市、物流类型、0.2° 网格预先汇总的全部记录，未随机抽样；全国节点在所属地区质心聚合显示，点击进入城市获取真实坐标。城市缩放到 13 级以上且视窗点量小于 6,500 时展示单点，否则继续聚合。需求热力按权重表达，不是连续统计估计或精确边界。

## 可重复生成数据

Python 3.10+，仅使用标准库，不重新运行原规划算法：

```powershell
python scripts/prepare_planning.py --source 'C:/Users/86181/Desktop/_out_v3_虚拟节点规划版.zip' --out dist/data/planning
python tests/preprocess_test.py
```

流程直接读取 ZIP，无需解压 1.29 GB 原始表。自动通过文件结构找根目录、按城市文件中的城市Key建立身份，哈希只用作安全文件名。布尔、空值、数字与字符串 ID 分别处理，列名原样保留。

输出：

- `dist/data/planning/index.json`：369 地区、全国及城市指标、加载路径、schema、manifest、run_status、逐城验证；约 807 KiB。
- `overview.json.gz`：23,563 个精确汇总格；约 1 MiB。
- `cities/*.json.gz`：8 张原始表的完整字段列式记录；合计约 110 MiB，最大单城约 2.63 MiB。
- `methods.json`：两份 Markdown 原文、研究验证报告、字段定义。
- `validation.json`：ZIP 哈希、各地区结果、根表行数、各项检查和执行时间。

检查失败会退出并报告异常，不跳过问题记录。数据更新时建议先使用独立 --out 路径生成并通过验证，再替换部署数据，避免半途失败留下混合版本。当前脚本中的 EXPECTED 针对本次交付，换数据后需要重新审查验收值。

空域更新沿用原脚本：

```powershell
./scripts/import-airspace.ps1 -Source '限飞区信息/限飞区.kml'
node scripts/verify-airspace.cjs '限飞区信息/限飞区.kml'
```

两个 KML 同源同哈希，仅导入一份；GDB/LYR/QGZ 未重复叠加。保留 58,553 个原始边界坐标与来源元数据。分类数量：限飞/禁飞 936、授权 649、警示 2,340、加强警示 29、管制 225、限制 28。

## 性能与交互

首屏读取索引与原空域；全国物流聚合、方法文档及城市明细按需请求。Worker 内解压、建图、空间网格索引、过滤、统计和导出。缓存最多两城，旧请求可取消，城市/地图/详情都有响应序号，避免过期结果覆盖新选择。Canvas 绘制需求与网络点，原空域 Leaflet 使用 Canvas；没有为几十万个需求点创建 DOM Marker。

全国聚合请求共用一个 Promise。城市空间查询使用 0.1° 网格粗筛和精确 bbox 复筛。城市缓存用 LRU 淘汰，不保存无限历史。大城市的完整字段仍有一定内存开销，浏览器内存上限未在所有设备上实测。

加载、失败重试、零结果、未选地区、零虚拟节点均有处理。手机端抽屉与底部详情、键盘可操作控件、焦点样式、比例尺、悬浮说明、可收起图例。分享链接保存城市/省份、模块、规划视图、情景、主要层级、需求类型和空域叠加；未保存精确地图中心与所有高级筛选值。

## 空域与模型边界

- KML 自述来源为 DJI FlySafe API，生成日期 2026-05-06；包含部分境外区域，未核验现行有效性。未提供限高或有效期，零高程不代表限高。
- 物流原始经纬度基准未独立确认。保留原值，没有猜测 GCJ-02 / WGS84 / BD-09 转换。点落入收录多边形的结果只是基于现有坐标的初步空间筛查，支持孔洞和边界判断；未命中不代表可飞。
- 非虚拟不等于现实已建成；虚拟点、共址位置都不是已运营设施。所有虚拟规划明确注明“模型规划位置｜未验证建设及运营条件”。土地不透水面分类不等于许可。
- 服务圆使用各城市各层真实模型半径，但只是地图示意。边距离为原模型投影平面距离，不是道路距离、飞行时间或真实航程。
- 原模型完整历史网络几何缺失，不能安全还原。页面只对比覆盖状态，所有可追踪线路明确属于规划情景。
- 100% 规划空间覆盖不代表 100% 可飞、建设可行或经济最优。预算、容量、土地审批、道路通达与空域许可没有全部成为硬约束。
- POI 按需求点邻域求和会重复计数，不是城市去重设施总量。全国需求强度/逐节点土地筛选需先选地区以读取明细；未伪造全国逐点分析。

## 独立部署与阿里云迁移

```powershell
python scripts/package_standalone.py
```

生成 `飞域-v3-独立部署包.zip`，包含 dist、Node 静态服务器、脚本、测试和本说明。直接把 `dist` 放到任意标准静态 Web 服务器的站点根目录即可，不需要 ChatGPT 账号或密钥。也可在自己的主机运行 Node 服务，再通过 Nginx 与 HTTPS 对外提供服务。

**gzip 部署要求**：`.json.gz` 是浏览器 Worker 自己解压的文件，请按普通二进制文件返回，不能额外设置 `Content-Encoding: gzip` 造成浏览器先解压、Worker 再解压。HTML/JS 建议协商缓存；若使用长期 CDN 缓存，更新数据时要同步刷新索引和城市文件缓存。

现有 `chatgpt.site` 发布地址的国内网络阻断无法通过前端代码解决。本次交付包含可迁移的静态版本，但没有实际购买、配置阿里云服务器、独立域名或办理备案。底图仍使用 OpenStreetMap 在线服务，国内可达性取决于网络；底图失败会提示，研究数据层仍可加载。未来更换地图服务必须同时核验服务许可与坐标体系，不能简单替换成不同坐标基准的瓦片。

## 主要代码

- `dist/index.html`、`platform.css`：五模块布局与响应式界面。
- `dist/platform.js`：地图、路由、筛选、详情、图表联动和导出交互。
- `dist/airspace.js`：复用原空域逻辑，新增叠加启闭和空间筛查。
- `dist/data-worker.js`：加载、LRU、索引、网络关联、聚合、统计、CSV。
- `dist/canvas-map.js`：Canvas 点、形状、聚合、热力与命中提示。
- `dist/core.js`、`charts.js`：共享几何/格式/CSV与可点击统计图表。
- `scripts/prepare_planning.py`：可重复数据标准化和完整校验。
- `tests/`：数据、Worker 与静态部署验证。

原 ZIP、解压目录、下载缓存、独立部署 ZIP 不进入源码版本管理，只保留必要可部署分片及代码。
