# 飞域 · 无人机空域速查

前期交互原型：全国地图浏览、40 个内置城市搜索、三类演示区域、图层筛选、区域详情、浏览器定位和移动端布局。

**所有彩色空域边界均为虚构演示，不能作为实际飞行依据。** 城市中心坐标仅用于定位地图；当前未接入官方空域、机场净空边界或临时管制通告。

## 本地运行

安装 Node.js 后，在此目录运行 `node server.cjs`，浏览器访问 `http://127.0.0.1:4173`。

静态页面在 `dist`，无需构建。Leaflet 1.9.4 从 unpkg 加载，底图来自 OpenStreetMap，需要网络连接。后续面向国内正式使用，可换成经授权的地图服务，并统一底图、位置和空域数据的坐标系。

## 后续数据接入

将 `dist/app.js` 的 `makeRecords` 演示数据替换为有合法来源的 GeoJSON 数据，并保留来源、有效时间、更新时间与适用条件。按实际几何边界绘制，不能把当前演示圆当作真实边界。正式数据不足时须继续显示“未核验”，不得把空白区域解释为可飞。
